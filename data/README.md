# Included data

The repository contains the small, curated inputs required to run the viewer
and to recompute its bundled time series. No download occurs at runtime.

## `toy/`

`syn_dataset.pkl` is a static synthetic graph with positions and labels. It is
used as the compact graph-only example in the viewer.

## `email/`

This is the complete email-network viewer example:

- `monthly_adjacency_lists.pkl`: 19 graph snapshots.
- `monthly_global_edge_scores.pkl`: explanation scores for each snapshot.
- `persistence_distances.json`: precomputed distances for the raw sequence.
- `persistence_distances_scored.json`: distances after applying the score
  threshold.

## `hsnet/latest/`

This is the current high-school contact-network example used by default:

- `monday1_dfs.pkl`: 19 processed snapshots, each with nodes and contact
  edges.
- `edge_importance_monday1_attention.csv`: edge importance generated by the
  explanation step.
- `results/{b,w}{0,1}_timeseries_monday1.json`: bottleneck/Wasserstein series
  for H0 and H1.

To regenerate the four HSNet result files from the processed snapshots and
importance CSV, run from the repository root:

```bash
python -m xplain_pipeline.analysis.persistence \
  --snapshots data/hsnet/latest/monday1_dfs.pkl \
  --importance data/hsnet/latest/edge_importance_monday1_attention.csv \
  --output-dir data/hsnet/latest/results
```
